# FRLG overworld maps

One file per map, named after the map in the
[pret/pokefirered](https://github.com/pret/pokefirered) decompilation
(`CeruleanCity.json`, `CeruleanCave_B1F.json`, ...). SerialPrograms plans
overworld routes on them (`PokemonFRLG_OverworldMaps.h`).

Generated by `devtools/maps/frlg_maps.py` in Arduino-Source from pokefirered
`ce6406d8c2ea`: each map's `map.json`, its layout's `map.bin` and its tilesets'
`metatile_attributes.bin`, plus the points and flag sets listed in the
generator. Don't edit them by hand; rerun the generator.

## Schema

| Field | Type | Meaning |
| --- | --- | --- |
| `name` | string | The map's decompilation name; the file is `<name>.json`. |
| `width`, `height` | int | Size in tiles. |
| `tiles` | `height` strings of `width` characters | What each tile is, row 0 at the top (legend below). |
| `elevation` | `height` strings of `width` hex digits | Each tile's elevation. Walking keeps to one elevation; 0 (stairs, ladders) joins them, and f ignores them. |
| `warps` | array of `{x, y, dest_map, dest_warp}` | Stepping on (x, y) goes to warp number `dest_warp` of `dest_map`. An empty `dest_map` is a map that isn't in this folder. |
| `objects` | array of `{x, y, kind, flag, wander_x, wander_y}` | Something standing on a tile: `kind` is its graphics (`nurse`, `item_ball`, `mewtwo`, ...). The game hides it once event flag `flag` is set; empty means always there. A wandering person may stand up to `wander_x`/`wander_y` tiles from (x, y). |
| `connections` | array of `{direction, offset, map}` | Walking off the `direction` edge (`north`, `east`, `south`, `west`) continues on `map`, shifted by `offset` tiles along that edge. Only maps in this folder are listed. |
| `points` | array of `{name, x, y}` | Places routes start or end at, e.g. `pc`, the tile in front of a Pokemon Center's PC. |
| `flag_sets` | array of `{name, flags}` | Event flags set together, e.g. `after_hall_of_fame`. Objects whose flag is set are gone. |

## Tiles

| Character | Tile |
| --- | --- |
| `#` | collision (wall, cliff) |
| `J` | ledge: a wall, except that walking into it the way it faces hops down |
| `.` | floor |
| `"` | tall grass: floor with wild encounters |
| `~` | water: entered only by starting to Surf |
| `D` | door: a wall that warps the player who walks north into it |
| `C` | cave entrance: floor that warps the player who steps onto it |
| `L` | ladder or escalator: floor that warps the player who steps onto it |
| `^` `v` `<` `>` | exit mat: floor that warps the player standing on it who walks the arrow's way |
| `n` / `s` / `e` / `w` | can't be entered moving south / north / west / east, or left moving north / south / east / west |
